# 安全子系统计划

更新日期：2026-02-10（当前主干）

本文件描述安全相关的组件、事件处理与配置原则，覆盖 Rate Limit、Snooping、IPSG 与 RBAC/审计。

## 目标
- 监测并限制异常 DHCP 行为，保护网络稳定。
- 对安全事件进行聚合、告警与可追溯审计。
- 与自动化/审批集成，实现自动隔离或快速封禁。

## 组件
- Rate Limit：按接口/VLAN 统计请求速率，超阈值触发告警与限速动作。
- Snooping：采集绑定关系与异常 DHCP 报文，输出安全事件。
- IPSG（如启用）：发布源保护策略至下游网络设备或记录事件。
- RBAC：服务侧权限控制，涵盖 API、CLI 与自动化任务。
- 审计：安全相关操作、告警抑制、封禁动作均写入审计。
- 认证：默认使用 Session Cookie（Secure + HttpOnly）或 Bearer Token，接口按角色/权限校验。

## 事件与动作
- 事件类型：速率超限、异常 DHCP 报文、未经授权的请求、配置漂移。
- 动作：
  - 警告：记录事件并通知值班。
  - 软封禁：对特定接口/设备限速或拒绝新租约。
  - 强封禁：阻断相关租约/池或向网络设备推送 ACL。
- 升级：在持续异常或短时间多次触发时升级到更高等级并通知安全负责人。

## 认证与会话安全
- Web：登录接口在 `/api/v1/auth` 前缀；Session Cookie 需 HTTPS 与 Secure，建议同域反代。
- API：支持 Bearer Token；敏感操作建议使用短期 Token 并结合审批。
- WebSocket：`wss://<域名>/api/v1/...` 复用同一认证，需反向代理透传 `Upgrade/Connection`。

## 配置建议
- 阈值按接口级别配置，避免局部异常扩大。
- 支持静默窗口，维护或演练时关闭自动封禁。
- 将敏感操作（解除封禁、修改阈值）纳入审批流。

## 可观测性
- 指标：事件数、封禁数、解除次数、速率分布（按接口/VLAN）。
- 日志：包含接口、MAC、VLAN、事件类型、动作、审批编号。
- 告警：
  - P1：持续封禁、短时高频超限、未经授权的 DHCP 服务器行为。
  - P2：单接口局部异常。
  - P3：配置漂移或阈值接近。

## 与其他模块的关系
- 自动化：安全事件可触发自动化任务执行隔离或批量清理。
- 监控：事件计数与速率进入 `/monitoring/overview` 供前端与告警使用。
- 存储：事件与封禁记录落库，供审计与追溯。
