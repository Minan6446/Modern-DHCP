# DHCP 请求处理管线

更新日期：2026-02-10（当前主干）

本文件描述 DHCPv4/v6 的处理阶段、可插拔钩子与与池/策略/审计的交互，便于调试与扩展。

## 阶段概览
- 监听：在指定接口/端口接收报文，完成基础校验（校验和、必需字段）。
- 解码：解析为内部消息结构（`internal/dhcpv4/message.go`, `internal/dhcpv6/message.go`）。
- 上下文构建：提取接口、VLAN、Option 元数据。
- 前置策略钩子：如报文合法性检查、速率限制（Rate Limit/Snooping）。
- 池解析：调用 `internal/pool` 解析最优池（基于 VLAN/接口/Location/SSID 等）。
- 策略执行：按阶段执行授权/变更策略（`internal/policy`）。
- 租约分配或续约：调用租约服务与仓储层；更新审计与指标。
- 响应编码：构建并发送 ACK/NAK/Advertise/Reply 等报文。
- 后置记录：写入监控快照与审计，必要时触发告警。

## 可插拔钩子
- 前置：报文过滤、速率限制、Snooping 校验、黑名单。
- 池解析钩子：可按接口/VLAN/位置定制选择策略或注入额外权重。
- 策略钩子：授权/拒绝、地址转换、Option 注入。
- 后置：审计补充、通知、异步自动化触发。

## 错误处理
- 解析失败：记录计数并丢弃；可按接口/VLAN 观察趋势。
- 池解析失败：根据 `pool.fallback` 决策（拒绝或使用备用池）。
- 租约写入失败：记录审计与指标，返回 NAK/拒绝；可触发告警。
- 策略拒绝：返回拒绝，并写入审计（含策略 ID/动作）。

## 审计与观测
- 指标：阶段耗时、成功/失败率、池命中率、策略命中率。
- 日志：包含接口、VLAN、池、策略、请求 ID。
- 审计：记录决策路径（池、策略、租约变更），用于追溯与合规。

## 扩展与调试建议
- 新增策略：实现策略接口并在 pipeline 注册；确保幂等且具备审计字段。
- 性能调优：
  - 避免在热点路径做阻塞 IO；策略需轻量。
  - 关注连接池与 SQL 计划，必要时添加索引。
- 测试：使用 `internal/dhcpv4/message_test.go`、`internal/dhcpv6/handler_test.go` 等作为样例，增加新场景用例。
