# 威胁响应与运行手册

本手册描述常见安全/可用性事件的响应步骤，便于值班快速执行。

## 1. 池耗尽或租约失败率上升
- 观察：`/monitoring/overview` 池可用容量 < 15% 或租约失败率 > 5%。
- 处置：
  - 短期：临时扩容权重较低的备用池；必要时释放过期租约。
  - 中期：创建新池或扩容子网，提交自动化任务，并记录审计。
  - 长期：调整容量规划，评估热点来源（按 VLAN/Location）。

## 2. HA 角色切换或复制延迟过高
- 观察：`/cluster/overview` 角色变化、复制延迟 > 阈值。
- 处置：
  - 确认数据库与网络健康，检查最近变更。
  - 若 Primary 异常，将其置为 Draining；确保 Secondary 提升成功。
  - 检查审计记录与日志，确认无长事务或锁竞争。
  - 恢复后按需要回切，并通知相关团队。

## 3. Rate Limit/Snooping 安全事件
- 观察：安全事件计数在 5 分钟内超过全局阈值，或触发 P1 告警。
- 处置：
  - 定位接口/VLAN，确认是否为攻击或配置错误。
  - 视情况执行软封禁或强封禁；记录审批编号。
  - 通知网络团队，检查上游设备与接入层。
  - 解除封禁前确保流量恢复正常，并记录审计。

## 4. 配置漂移或策略误发布
- 观察：审计中出现未批准的策略变更或与预期模板不符。
- 处置：
  - 立即暂停相关自动化任务；回滚到上一个已知良好版本。
  - 通知变更发起人与审批人，补充审计记录。
  - 检查 RBAC 与审批配置，防止再次发生。

## 5. 数据库异常（慢查询/连接池耗尽）
- 观察：慢查询告警、连接池满、请求延迟升高。
- 处置：
  - 确认是否存在未完成迁移或异常查询；临时调整连接池上限慎用。
  - 优先缓解：降级非关键接口、限制写入。
  - 长期：优化查询与索引，必要时垂直/水平扩容。

## 通用要求
- 所有处置动作需写入审计：事件类型、决策人、时间、影响范围。
- 告警抑制应有时间窗与责任人，结束后解除。
- 事后复盘：在 24-48 小时内完成，产出行动项与指标校验。
